# على رفوف المساجد

## 🤝 كيف تساهم في المشروع؟

السلام عليكم ورحمة الله وبركاته. يسعدني جداً اهتمامك بالمساهمة في مشروع **على رفوف المساجد**. سواء كنت تريد إصلاح خطأ بسيط ، أو إضافة ميزة جديدة ، فإن مساهمتك تصنع فرقاً.

لقد صممنا هذا الدليل لمساعدة المطورين المبتدئين على البدء بسهولة.
---
### 🛠 خطوات المساهمة (خطوة بخطوة)

#### 1. عمل Fork للمشروع

قم بالضغط على زر **Fork** الموجود في أعلى الصفحة جهة اليمين. سيؤدي ذلك إلى إنشاء نسخة من المشروع داخل حسابك الشخصي على GitHub.

<img width="717" height="241" alt="image" src="https://github.com/user-attachments/assets/0b6dbfd5-0eea-4e61-9196-8bd3d19cae49" />

#### 2. تحميل المشروع لجهازك (Clone)

افتح الـ Terminal في جهازك وقم بتحميل نسختك الخاصة:

```bash
git clone https://github.com/YOUR-USERNAME/Mosque-Books.git
cd Mosque-Books
```

#### 3. ابدأ العمل!

قم بإجراء التعديلات التي تريدها. بعد الانتهاء، قم بحفظ التعديلات:

```bash
git add .
git commit -m "اكتب هنا وصفاً بسيطاً لما قمت بتغييره"
git push
```

#### 5. إرسال طلب سحب (Pull Request)
طريقتان:
1. اذهب إلى المشروع الأصلي [بين رفوف المساجد](https://github.com/BelalAmrMohamed/Rofoof). ستظهر لك رسالة خضراء تقترح عليك عمل **"Compare & pull request"**. اضغط عليها، واشرح باختصار ما قمت به، ثم أرسل الطلب!

2. اذهب إلى المشروع الموجود على حساب GitHub الخاص بك واضغط على زر ال **Contribute** ، ثم اضغط على **Open pull request**. أكمل الخطوات ، وهكذا قمت برفع تغييراتك الخاصة على المشروع الأصلى:

### 💡 نصائح للمطورين الجدد

- **إعمل على مهمة واحدة:** لا تحاول تغيير المشروع بالكامل مرة واحدة، المميزات أسهل في المراجعة والقبول.
- **لا تتردد في السؤال:** إذا واجهت أي مشكلة تقنية، يمكنك التواصل مع المطوّر ، وسأساعدك بكل سرور.
