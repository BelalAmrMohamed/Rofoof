👤
Guest Browses Books
Actor: Guest (no account)
1
Lands on platform → sees /login
2
Clicks "تصفح بدون تسجيل" (Skip login)
3
Lands on /browse — prompted to set location
4
Selects governorate + city from dropdowns
5
Books appear sorted by mosque proximity
6
Searches / filters by category, city, etc.
7
Clicks a book → /browse/book/:id
Sees which mosque has the book ✓
📚
Volunteer Submits a Book
Actor: Volunteer (authenticated)
1
Clicks "تسجيل كتاب" in nav
2
Session detected → /submit loads directly
3
Fills book info: title*, author, category, edition, notes, image
4
Searches for mosque by name / city
Mosque already exists on platform?
5
✓ Found
Selects mosque from dropdown
✗ Not found
Expands inline form: governorate*, city*, name, image
6
Clicks Submit
7
System sets status = approved
Book immediately visible in browse ✓
✋
User Requests to Add a Book
Actor: Registered User (non-volunteer)
1
Clicks "تسجيل كتاب" → no session → /login
2
Registers with email, sets name + location
3
Redirected to /submit
4
Fills book + mosque info (same form as volunteer)
5
Submits → system sets status = pending
6
Sees confirmation: "طلبك قيد المراجعة"
7
Submission appears in admin /requests
Awaits admin approval ✓
🛡️
Admin Reviews a Submission
Actor: Admin
1
Navigates to /requests
2
Views pending submissions list
3
Clicks submission to expand: book info, mosque, submitter
What does admin decide?
4
Path A — Approve
Clicks "موافقة" → status = approved → book goes live
Path B — Edit & Approve
Edits fields → saves → status = approved → book goes live
Path C — Reject
Enters reason → confirms → status = rejected → book stays hidden
Decision logged with timestamp ✓
